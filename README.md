# 本地音乐播放器

支持播放本地 MP3 文件，显示 LRC 歌词，顺序播放和随机播放。

## 使用方法

1. 直接双击打开 `index.html`，或使用本地服务器运行
2. 添加歌曲的方式：
   - **选择文件**：点击或拖拽 MP3/LRC 文件到上传区域
   - **选择文件夹**：点击「选择文件夹」按钮，在弹出窗口中选择音乐所在目录（需 Chrome/Edge 等支持 File System Access API 的浏览器）
3. 若要显示歌词，LRC 需与 MP3 同名（如 `歌曲名.mp3` 和 `歌曲名.lrc`）
4. 点击播放列表中的歌曲开始播放

## 功能

- 播放本地 MP3/M4A/OGG/WAV 文件
- 支持选择文件夹批量添加（会递归包含子文件夹）
- 支持 LRC 格式歌词，自动同步显示
- 顺序播放：按列表顺序依次播放
- 随机播放：随机打乱播放顺序
- 点击进度条可快进/快退
- 上一首/下一首切换

## LRC 歌词格式

```lrc
[00:12.00]第一句歌词
[00:18.50]第二句歌词
[00:24.00]第三句歌词
```

## 提示

- 使用本地服务器（如 `npx serve .`）可避免部分浏览器的跨域限制
- LRC 文件需与 MP3 文件**同名**（仅扩展名不同）
